# لا تجلس طويلًا (Health Reminder)

تطبيق أندرويد بسيط **يذكّرك بكسر الجلوس والحركة** بهدوء وبلا صوت، حفاظًا على صحّتك.

## الفكرة
عند حلول وقت الفترة، يغطّي التطبيق الشاشة **بخلفية جميلة متغيّرة** وعبارات تحفيزية
صحّية مع **عدّاد تنازليّ**، ولا تُفتح الشاشة إلا **بانتهاء المدّة** أو **إدخال رمز
معقّد** (للضرورة). بلا صوت — راحة بصرية هادئة تدعوك للحركة.

## المزايا
- **حتى ٣ فترات** يوميًّا: لكل فترة وقت بداية + **مدّة حركة** بالدقائق (تُحسب النهاية تلقائيًّا).
- **تغطية صامتة** بخلفيات متدرّجة متغيّرة + عبارات صحّية (اشرب ماء، تنفّس بعمق، تحرّك بهدوء…).
- **رمز تخطٍّ** اختياريّ لفتح الشاشة قبل انتهاء الوقت عند الضرورة (اتركه فارغًا لمنع التخطّي).
- **إشعار صامت بملء الشاشة** عند حلول الفترة — يعمل حتى لو كان التطبيق مغلقًا (يُعاد جدولته بعد إعادة التشغيل).
- عربيّ RTL بالكامل، بلا حسابات ولا إنترنت.

## التشغيل والبناء
```bash
flutter pub get
flutter run                 # للتطوير
flutter build apk --release # ناتج: build/app/outputs/flutter-apk/app-release.apk
```

## البنية
```
lib/
├─ main.dart            # الإقلاع + الثيم + RTL
├─ home_screen.dart     # الرئيسية: الحالة، الفترة القادمة، تجربة
├─ settings_screen.dart # ضبط الفترات والرمز
├─ break_screen.dart    # شاشة التغطية الصامتة + العدّاد
├─ break_service.dart   # الإعداد ومنطق الفترات (SharedPreferences)
└─ notify_service.dart  # جدولة الإشعارات الصامتة بملء الشاشة
```

## ملاحظات
- التغطية داخل التطبيق تعمل عند فتحه؛ والإشعار بملء الشاشة يُنبّه عند الإغلاق ويفتح
  التطبيق على شاشة الحركة. فرض القفل فوق **بقية التطبيقات** يتطلّب صلاحية «العرض فوق
  التطبيقات» ويمكن إضافته لاحقًا.
- الإصدار الحاليّ يوقَّع بمفتاح debug؛ للنشر أضِف مفتاح توقيع خاصًّا (`key.properties`).
