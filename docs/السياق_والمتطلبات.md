# السياق والمتطلبات — تطبيق «لا تجلس طويلًا»

هذا الملف يوثّق **أصل الفكرة وطلب المالك وقرارات التصميم** ليكون مرجعًا دائمًا،
وليتابع أي مطوّر (أو جلسة Claude لاحقة) العملَ من حيث انتهى. **كل التحديثات
المستقبلية تُجرى في هذا المستودع** (`alaoufi/health_reminder`).

---

## 1) طلب المالك (نصًّا كما ورد)

> اريد نوع تنبيه جديد اسمه **لا تجلس طويلا** — تذكير بالحركة وكسر الجلوس بضوابط.
>
> **أولًا** بدون صوت، فقط تغطية الشاشة بصورة جميلة متغيّرة، عليها عبارة:
> - «جلستَ كثيرًا، ولصحّتك لن نسمح لك بضرر صحّتك، ضروريّ تتحرّك بهدوء فقط … دقائق ثم تعود لعملك، صحّتك مهمّة فحافظ عليها».
> - «في هذه الفترة البسيطة استغلّها لصحّتك: اشرب ماء، وتنفّس بعمق، وتحرّك بهدوء».
>
> **ثانيًا** تقسَّم فترات: فترة ١ من الساعة … إلى الساعة … بالدقائق، ومدّة الحركة
> بالدقائق. **ممكن تكون ثلاث فترات**.
>
> **لا تُفتح الشاشة إلا بعد انتهاء المدّة أو إدخال رقم معقّد.**
>
> اعملها في **تطبيق منفصل** في مستودع جديد: `alaoufi/health_reminder`،
> واعتمد **الشعار: «لا تجلس طويلًا»**.

---

## 2) قرارات التصميم (كيف طُبّق الطلب)

| المتطلب | القرار في التنفيذ |
|---|---|
| بلا صوت | لا صوت ولا اهتزاز إطلاقًا؛ الإشعار قناته `playSound:false, enableVibration:false`. |
| صورة/خلفية جميلة متغيّرة | خلفيات **متدرّجة** (٦ تدرّجات هادئة) تتبدّل كل ٦ ثوانٍ (بلا أصول صور خارجية لخفّة الحجم). |
| العبارات التحفيزية | عبارتا المالك + عبارتان إضافيتان، تتناوب مع الخلفية. |
| الفترات (من/إلى + مدّة) | كل فترة = **وقت بداية** + **مدّة حركة (دقائق)**، والنهاية = البداية+المدّة تُحسب وتُعرض تلقائيًّا. |
| ثلاث فترات كحدّ أقصى | نعم — الإعدادات تسمح بإضافة/حذف حتى ٣. |
| لا تُفتح إلا بانتهاء المدّة أو رقم معقّد | شاشة غير قابلة للإغلاق (`PopScope canPop:false`)؛ تُغلق فقط بانتهاء العدّاد أو إدخال **رمز التخطّي** الذي يضبطه المالك (فارغ = منع التخطّي). |
| تطبيق منفصل | مشروع Flutter مستقلّ `com.alaoufi.health_reminder`. |
| الشعار | اسم التطبيق والعنوان: **«لا تجلس طويلًا»**. |

قرارات تقنية إضافية:
- **التوقيت الزمنيّ:** ثُبّت على `Asia/Riyadh` (UTC+3 بلا توقيت صيفيّ) بعد إزالة
  حزمة `flutter_timezone` التي كانت تكسر بناء أندرويد (تعارض JVM: Java 11 مقابل
  Kotlin 1.8).
- **الإشعار الصامت بملء الشاشة** (`fullScreenIntent`) مجدول يوميًّا لكل فترة عبر
  `flutter_local_notifications` + `timezone`، ويُعاد جدولته بعد إعادة التشغيل.
- التخزين محليّ عبر `SharedPreferences`؛ لا إنترنت ولا حسابات.

## 3) ما أُنجز (النسخة 1.0.0)

- الواجهة الرئيسية: حالة التفعيل + الفترة القادمة + ملخّص الفترات + زرّ «جرّب الآن».
- شاشة التغطية الصامتة: خلفيات متغيّرة + عبارات + عدّاد تنازليّ + تخطٍّ بالرمز.
- الإعدادات: تفعيل، فترات (بداية/مدّة/تفعيل)، رمز التخطّي.
- إشعارات صامتة بملء الشاشة مجدولة يوميًّا.
- عربيّ RTL كامل، اختبارات وحدات للنموذج.

## 4) حدود النسخة الحالية

- التغطية **داخل التطبيق** تعمل عند فتحه؛ والإشعار بملء الشاشة يُنبّه عند الإغلاق
  ويفتح التطبيق على شاشة الحركة. **القفل فوق بقية التطبيقات** (خارج التطبيق)
  يتطلّب صلاحية «العرض فوق التطبيقات» (`SYSTEM_ALERT_WINDOW`) + خدمة أمامية.
- التوقيع الحاليّ **debug** — للنشر يلزم مفتاح توقيع خاصّ (`key.properties`).

## 5) خارطة التطوير (التالي)

1. **قفل فوق كل التطبيقات** عبر Overlay (`SYSTEM_ALERT_WINDOW`) + Foreground Service.
2. **مفتاح توقيع خاصّ** + إعداد نشر (وربّما Google Play).
3. **أيقونة/لوجو** مخصّص بالشعار «لا تجلس طويلًا».
4. **CI** تلقائي (تحليل + بناء APK) لهذا المستودع.
5. خيارات إضافية: صور خلفية حقيقية اختيارية، أيام الأسبوع لكل فترة، إحصاء الالتزام.

> **مبدأ:** أي طلب تحديث لهذا التطبيق يُنفَّذ هنا (في `alaoufi/health_reminder`)،
> ويُوثَّق أثره في هذا الملف تحت «سجلّ التحديثات» أدناه.

## سجلّ التحديثات

- **إصلاح تجمّد نافذة القفل (حرج)** — كانت نافذة القفل فوق كل التطبيقات
  (`overlay_break.dart`) تعتمد كلّيًّا على قراءة وقت الانتهاء (`hr_active_end`)
  من `SharedPreferences` داخل عزلتها المنفصلة. إن رجعت القراءة `null` (سباق زمنيّ
  مع الكتابة، أو فشل صامت، أو عدم رؤية العزلة للقيمة) كان المؤقّت لا يعدّ ولا يُغلق
  أبدًا، فيظهر العدّاد `00:00` ثابتًا وتبقى الشاشة فوق كل شيء بلا مخرج (تجمّد يستلزم
  إعادة تشغيل الجهاز). **الإصلاح:** ضمان نهاية صالحة دائمًا (نهاية بديلة من مدّة
  الراحة المخزّنة في `hr_active_minutes` عند غياب وقت الانتهاء)، **سقف أقصى مطلق
  ٣٠ د**، **مؤقّت أمان مستقلّ** يُغلق النافذة مهما تعطّل المؤقّت الرئيسيّ، عرض العدّاد
  فورًا بلا ثانية `00:00` أولى، وإغلاق أحاديّ (idempotent) ينظّف علامة النشاط.
- **1.0.0** — النسخة الأولى: التنبيه الصامت، الفترات (حتى ٣)، رمز التخطّي،
  الإشعارات المجدولة. (نُقلت الفكرة من ميزة داخل تطبيق «ملاحظات» إلى تطبيق مستقلّ.)
